# Netflix Clone with Firebase and TMDB API

Welcome to my Netflix clone project! In this project, we build a front-end Netflix clone using React, with a Firebase back-end for authentication and cloud storage. The data for the movies and TV shows is fetched using the TMDB (The Movie Database) API, and Firebase Firestore is used to store user-specific data. We use Firebase Authentication for user login and Tailwind CSS for styling. Finally, the app is deployed live with Firebase Hosting.

## 🚀 Features

- **React Front-End**: Build a responsive UI for a Netflix-like experience.
- **Firebase Authentication**: Users can log in securely with their credentials.
- **TMDB API Integration**: Fetch movie and TV show data from TMDB to display content.
- **Firestore Storage**: Store and retrieve user-specific data such as favorites or watchlist.
- **Tailwind CSS**: Use Tailwind for efficient and easy-to-use styling.
- **Firebase Hosting**: Deploy the app live with Firebase Hosting for public access.

## 🔧 Technologies Used

- **React**: Front-end framework to build the user interface.
- **Firebase**: Backend services for authentication, database (Firestore), and hosting.
- **TMDB API**: Used to fetch movie and TV show data.
- **Tailwind CSS**: Utility-first CSS framework for responsive and customizable styling.
